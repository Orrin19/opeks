## Риски и меры

| Риск | Мера |
| --- | --- |
| Изменение поведения команд при рефакторинге | Фазы идут «слоями»; после каждой — ручной smoke-тест; базовые классы сохраняют текущую логику ответов. |
| Поломка регистрации команд | Сначала исправить `ready.ts`, затем мигрировать команды. |
| LLM/вики-сервисы отличаются поведением | Единый `LlmService`/`WikiService` с тестами на моках. |
| Зависимость от `ts-node` в проде | Ввести `build` + `dist` до переноса сервисов. |
| Потеря локализаций (ru/uk) | Сохранить все `*Localizations` при переносе на классы. |

## Риски и меры

| Риск                                        | Мера                                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Изменение поведения команд при рефакторинге | Фазы идут «слоями»; после каждой — ручной smoke-тест; базовые классы сохраняют текущую логику ответов. |
| Поломка регистрации команд                  | `clientReady` подтверждён корректным; регистрация в `ReadyListener`.                                   |
| LLM/вики-сервисы отличаются поведением      | Единый `LlmService`/`WikiService` с тестами на моках.                                                  |
| Зависимость от `ts-node` в проде            | Введён `build` + `dist`; прод запускается из `dist/index.js`.                                          |
| Потеря локализаций (ru/uk)                  | Сохранены все `*Localizations` при переносе на классы.                                                 |

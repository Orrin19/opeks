`parsers/index.ts` и `listeners/index.ts` (см. [architecture.md](architecture.md)).

### `/dice` — запрос на бросок куба

Команда для ведущего (роли `DICE_ROLE_NAMES` из `config/constants.ts`). Ведущий
указывает назначение, игрока, диапазон (по умолчанию 1–20), модификаторы в формате
`+1 Ловкость, -2 Усталость` и опциональный порог сложности. Бот пинает игрока и
выводит эмбед с кнопкой «Бросить куб». Кнопку может нажать только указанный игрок:
при нажатии бот отвечает на своё же сообщение результатом (бросок, модификаторы,
итог, успех/провал относительно порога). Параметры броска хранятся в
`DiceService` (in-memory) до нажатия кнопки.

### `/dice-range` — бросок с диапазонами результатов

Та же механика, что и `/dice`, но вместо одного порога сложности ведущий задаёт
набор диапазонов с результатами в формате
`1-5:провал; 6-15:частичный успех; 16-20:полный успех`. Итог броска (бросок +
модификаторы) попадает в один из диапазонов — бот выводит соответствующий
результат. Крайние диапазоны считаются открытыми: итог ниже нижней границы
относится к нижнему диапазону, выше верхней — к верхнему (так модификаторы не
могут «выбить» результат за пределы диапазонов). Предупреждение выводится только
если итог попадает в разрыв между несмежными диапазонами. Обе команды наследуют
общий класс `DiceRequestCommand`, а парсинг диапазонов — в
`utils/dice.ts` (`parseThresholds`, `resolveThreshold`, `formatThresholds`).

## Парсеры сообщений (6)

Реакция на обычные сообщения (не команды). Классы-наследники `TextParser` в
`src/parsers/`.

| Парсер       | Файл            | Условие `matches`                           | Действие                               |
| ------------ | --------------- | ------------------------------------------- | -------------------------------------- |
| BotQuestion  | BotQuestion.ts  | бот упомянут, сообщение оканчивается на «?» | случайный ответ «да/нет»               |
| WikiLinks    | WikiLinks.ts    | текст содержит `[[...]]`                    | раскрывает ссылки на статьи вики       |
| Marsel       | Marsel.ts       | «хочу марсель» / «хочу в марсель»           | выдаёт/снимает роль «Марсель»          |
| RandomEmoji  | RandomEmoji.ts  | случайный шанс ~1/200 (и автор не бот)      | случайный эмодзи: отправка или реакция |
| ReactTrigger | ReactTrigger.ts | всегда (фильтр — внутри `run`)              | реакция-эмодзи на триггер-слова        |
| Univermag    | Univermag.ts    | «искать/найти/взять инструменты»            | выдаёт/снимает роль «Тушкан»           |

Триггер-слова для `ReactTrigger` лежат в `parsers/triggers/TriggerWords.ts`
(интерфейс `TriggerWord`: `{ trigger: RegExp; emojiName: string; chance: number }`).
